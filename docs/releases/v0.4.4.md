# 经典艾莉丝 0.4.4

本版本在 Electron 桌宠中保留经典红发艾莉丝形象、自动入睡和左右相邻屏幕间的自动行走，并加入：

- 导入 EPUB/TXT 电子书，按章节建立本地索引；对话时检索相关片段，不宣称一次读完或永久记住全书。
- 天气问题查询 Open-Meteo；其他需要实时信息的问题使用在线搜索摘要，并注明来源和信息范围。
- 可编辑的长期用户设定，跨角色保存；不会自动从聊天中提取个人信息。
- 可选、限频的主动聊天；仍需用户自行配置模型接口。

Windows x64 提供单文件便携 EXE 和包含使用说明的 ZIP。首次运行会在 EXE 所在目录创建 `data`，以后迁移时请一起复制。发布包不预置 API 密钥、聊天记录或用户书库。

已在本地完成 162 项自动测试、资源校验、隐私扫描及便携程序启动/搬迁验证。双屏实体设备、其他电脑和用户实际 EPUB 尚未完成实测。应用未签名，Windows 可能显示安全提示。
